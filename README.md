# Site Web pour un Chef Cuisinier

## Description
Ce projet consiste à développer un site web pour un chef cuisinier, permettant aux utilisateurs de découvrir des menus exclusifs et de réserver des expériences culinaires à domicile. Les chefs peuvent gérer les réservations, consulter des statistiques et gérer leur profil.

## Fonctionnalités principales
- **Utilisateurs (Clients)** :
  - S'inscrire et se connecter.
  - Découvrir les menus du chef.
  - Réserver des expériences culinaires.
  - Gérer leurs réservations (historique, modification, annulation).
  
- **Chefs (Administrateurs)** :
  - Gérer les réservations (accepter ou refuser).
  - Consulter des statistiques sur les réservations.
  - Gérer les menus.

## Technologies utilisées
- **Frontend** : HTML5, CSS3, JavaScript (Responsive Design)
- **Backend** : PHP
- **Base de données** : MySQL
- **Sécurité** : Hashage des mots de passe, prévention des attaques  SQL
